I first put this site together back in 2016 as a Jekyll page with a word cloud and a list of college projects.
A lot has changed since then: SAP, a master's at UC Davis, Amazon, and now building infrastructure for
Generative AI agents at Oracle Cloud.

The site is now built with [Astro](https://astro.build) and deployed to GitHub Pages with GitHub Actions.
Each post is just a Markdown file.

## What I plan to write about

- **Agent infrastructure**: control planes, sandboxes and gateways for LLM agents.
- **Kubernetes in practice**: operators, autoscaling and multi-tenancy lessons.
- **Distributed systems**: consensus, rate limiting and everything in between.

Thanks for stopping by. You can follow along via [RSS](/rss.xml).
